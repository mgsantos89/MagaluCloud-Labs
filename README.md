# Magalu Cloud Labs

Repositório dedicado ao estudo prático e aprofundamento em **Magalu Cloud**, com foco em Cloud, DevOps, Kubernetes, Terraform, Observabilidade, Segurança e FinOps.

## 🎯 Objetivo

Construir uma trilha prática para dominar a plataforma Magalu Cloud, explorando seus principais serviços e desenvolvendo arquiteturas próximas de cenários reais de produção.

A jornada também busca avaliar a plataforma sob a perspectiva de um profissional já experiente em **AWS, Kubernetes e DevOps**, identificando equivalências, diferenças, limitações e oportunidades.

## 🧪 Labs

A evolução será organizada em fases:

1. Fundamentos da Magalu Cloud
2. Compute e Networking
3. Storage
4. Database
5. Kubernetes
6. Terraform e IaC
7. CI/CD
8. Observabilidade
9. Segurança
10. FinOps
11. Arquiteturas e migração AWS → Magalu Cloud

Cada fase terá laboratórios práticos, documentação, código e, quando aplicável, cenários de falha e recuperação.

## 🚀 Resultado esperado

Ao final da jornada, o objetivo é possuir experiência prática suficiente para:

* Projetar arquiteturas na Magalu Cloud
* Provisionar infraestrutura com Terraform
* Operar workloads Kubernetes
* Implementar CI/CD
* Implementar observabilidade e segurança
* Avaliar custos e oportunidades de FinOps
* Comparar AWS e Magalu Cloud
* Projetar estratégias de migração entre as plataformas

> **Aprender na prática, documentar e transformar conhecimento em arquiteturas reutilizáveis.**
